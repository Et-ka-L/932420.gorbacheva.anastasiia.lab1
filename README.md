## О работе

Работа является продолжением Lab 1: страница оформлена внешним CSS-файлом
и дополнена интерактивными элементами. Основная идея — тёмный фон, 
электрический голубой акцент, футуристические шрифтыOrbitron и Rajdhani,
глитч-мерцание заголовков карточек при наведении.

## Файлы
`index.html`  Основная HTML-страница
`style.css`  Внешний файл стилей
`images`  Папка с изображениями, использующимися на странице

## Как запустить

1. Скачать/склонировать репозиторий.
2. Открыть `index.html` в браузере (Chrome, Firefox, Edge).
